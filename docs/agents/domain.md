# Domain docs

Reconcilio uses a single-context layout. The root `GLOSSARY.md` defines domain terms, and `docs/adr/` records architecture decisions.

## Before exploring

Read `GLOSSARY.md` and the ADRs in `docs/adr/` relevant to your task. If either is absent, proceed silently. The domain-modeling skill adds these docs when domain terms or decisions are settled.

## Use domain terms and surface conflicts

Use the glossary's terms in issues, proposals, hypotheses, and tests. If a term is missing, flag the gap for domain modeling.

If a proposal conflicts with an ADR, cite the ADR and explain why the decision may need revisiting.
