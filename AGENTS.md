## Agent skills

### Issue tracker

Issues and specs live in GitHub Issues for `kmmenna/reconcilio`. See `docs/agents/issue-tracker.md` when reading or publishing tickets.

### Triage labels

Reconcilio uses the default Matt Pocock triage labels. See `docs/agents/triage-labels.md` when applying a triage role.

### Domain docs

Reconcilio uses a single-context layout with a root `GLOSSARY.md` and ADRs in `docs/adr/`. See `docs/agents/domain.md` before exploring the domain.
